## Citrus Dataset Analysis and Exploratory Data Analysis Framework

**Current Stage:** Dataset Analysis & Exploratory Data Analysis (EDA)

---

## 📌 About the Project

**CitrusAI-X** is a research-oriented project for analyzing and understanding
a large-scale citrus leaf image dataset before developing machine learning
and deep learning models.

The current work focuses only on:

- Dataset organization
- Dataset validation
- Image analysis
- Class distribution
- Image dimension analysis
- Dataset quality
- Class imbalance
- Exploratory Data Analysis (EDA)

> **Note:** CNN, VLM, RAG, Explainable AI, and treatment recommendation are
> future stages of the overall research project and are not part of the
> current implementation.

---
